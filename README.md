# MGT102 Fundamentals of Management — Interactive Worksheets

32 interactive worksheets, one for each lecture of MGT102 Fundamentals of Management (BS(BA) / BS(BAF), Semester 1). Textbook: Robbins & Coulter, *Management*.

Every worksheet has five tabs:

1. **What-if calculator** — sliders that apply a fixed formula (e.g. efficiency vs effectiveness, break-even, span of control, expectancy E×I×V, Motivating Potential Score). Nothing changes over time; you change the inputs and see the result.
2. **Sorting exercise** — click items into the right category (or put steps in order), then check answers with explanations.
3. **Dilemma scenario** — two linked decisions in a Pakistani workplace case; each choice moves three scores, followed by a debrief.
4. **Selector** — weight the criteria and see which option fits best (e.g. management function, entry mode, structure, leadership style, control tool).
5. **Concept check** — five multiple-choice questions with instant feedback.

Each page also has a short concept primer and discussion questions.

**Open the worksheets:** `https://nilblue.github.io/mgt102-fundamentals-of-management-labs/` (GitHub Pages: Settings → Pages → Deploy from branch → `main` / root). You can also download the repo and open `index.html` in any browser; no install or internet connection is needed.
